# ADR 001. Границы первого этапа

Статус: принято в рамках согласованного поэтапного плана.

Три серверных процесса: ingestion, processor, api. Управление устройствами
объединено с REST API; обнаружение аварий на следующем этапе размещается
в processor для общей транзакции с сохранением измерений.

Один Go-модуль упрощает сборку; каждый процесс имеет отдельную точку входа.
Один экземпляр PostgreSQL является осознанной связью сервисов первого этапа.
Ролевое разделение БД и read-only представления будут введены до завершения MVP.

На первом этапе MQTT 3.1.1 через Paho mqtt.golang: QoS 1, постоянная сессия
ingestion, ручной ACK. В базовом срезе не используются свойства MQTT 5.
Переход на Paho MQTT 5 выполняется перед исследованиями shared subscriptions
и поведения receive limits, если эти возможности потребуются.

Первый срез хранит одну транзакцию на сообщение и использует общее MQTT
соединение генератора. Это исходная конфигурация для измерений, не заявление
о достижении высокой нагрузки. Все версии Go-модулей закреплены go.mod/go.sum,
версии контейнеров закреплены тегами в Compose.
